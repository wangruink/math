数轴画法三字诀：
1. 定点：画实心还是空心？（含等号 $\le, \ge$ 实心点；不含等号 $<, >$ 空心圈）
2. 交集（公共部分）：“有空则空，双实才实”——只有同时包含该端点，交集端点才为实心。
3. 并集（全部覆盖）：“有实则实”——只要有一个集合包含该端点，并集即包含该端点。

交集 (Intersection) $A \cap B$ 公共部分 (AND)
$A \cap B = (1, 3)$
属于集合 $A$ 且 属于集合 $B$ 的所有实数构成的区域。
并集 (Union) $A \cup B$ 合并所有 (OR)
$A \cup B = [-2, 5]$
属于集合 $A$ 或 属于集合 $B$ 的所有实数覆盖的全部区域。
