向量的几何表示

我们可以用带箭头的线段来表示向量，线段按一定比例（标度）画出，它的长短表示向量的大小，箭头的指向表示向量的方向。


通常，在线段 $AB$ 的两个端点中，规定一个顺序，假设 $A$ 为起点、$B$ 为终点，我们就说线段 $AB$ 具有方向。**具有方向的线段叫做有向线段**（directed line segment）。

例 1 变式

如图所示，在平行四边形 $ABCD$ 中，成立的是（　　）

A．$\overrightarrow{AB} = \overrightarrow{DC}$　　B．$\overrightarrow{AB} = \overrightarrow{CD}$

C．$\overrightarrow{AD} = \overrightarrow{CB}$　　D．$\overrightarrow{AD} = \overrightarrow{BC}$


分析：由平行四边形的性质及相等向量的定义，$\overrightarrow{AD}$ 与 $\overrightarrow{BC}$ 方向相同且长度相等，故 $\overrightarrow{AD} = \overrightarrow{BC}$。

答案：D

例 2

如图 6.1-8，设 $O$ 是正六边形 $ABCDEF$ 的中心。（1）写出图中的共线向量；（2）分别写出图中与 $\overrightarrow{OA}$，$\overrightarrow{OB}$，$\overrightarrow{OC}$ 相等的向量。

解：(1) 共线向量：

$\overrightarrow{OA}$ 与 $\overrightarrow{OD}$；$\overrightarrow{OB}$ 与 $\overrightarrow{OE}$；$\overrightarrow{OC}$ 与 $\overrightarrow{OF}$；

$\overrightarrow{AB}$ 与 $\overrightarrow{DE}$；$\overrightarrow{BC}$ 与 $\overrightarrow{EF}$；$\overrightarrow{CD}$ 与 $\overrightarrow{FA}$。

(2) 与 $\overrightarrow{OA}$ 相等的：$\overrightarrow{EF}$，$\overrightarrow{CB}$；

与 $\overrightarrow{OB}$ 相等的：$\overrightarrow{FA}$，$\overrightarrow{DC}$；

与 $\overrightarrow{OC}$ 相等的：$\overrightarrow{AB}$，$\overrightarrow{ED}$。

例 2 变式

如图，$O$ 为正方形 $ABCD$ 对角线的交点，四边形 $OAED$，$OCFB$ 都是正方形。在图中所示的向量中：（1）分别写出与 $\overrightarrow{AO}$，$\overrightarrow{BO}$ 相等的向量；（2）写出 $\overrightarrow{AO}$ 的相反向量；（3）写出与 $\overrightarrow{AO}$ 模相等的向量。


思考：相等向量 / 相反向量 / 模相等的向量如何逐一找出？（由平行四边形性质与相等向量定义判断）
